# Segnalazioni di sicurezza

Per segnalare un problema, usa **Security → Report a vulnerability** nel repository pubblico. Indica la versione, la piattaforma e il componente interessato. Rimuovi credenziali, dati reali e percorsi personali dagli allegati.

I comandi della toolchain eseguono il codice e gli script del progetto scelto. Avvia solo progetti e comandi di cui conosci la provenienza.
