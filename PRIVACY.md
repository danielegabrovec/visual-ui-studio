# Dati e connessioni di Visual UI Studio

Visual UI Studio conserva progetti, configurazione, cronologia SQL e dati di lavoro nel profilo della tua utenza o nelle cartelle che scegli. Su Windows la directory del profilo si trova sotto `%APPDATA%`. La modalità browser conserva i progetti nel browser.

L’app non include telemetria o servizi di raccolta dati gestiti dall’autore. I prompt e il contesto che autorizzi vengono inviati al provider AI selezionato. Ollama e LM Studio possono operare localmente. Un provider remoto o un modello con elaborazione remota riceve le richieste secondo la propria configurazione e informativa.

Quando usi un database remoto, il server configurato riceve le query e i relativi parametri. Le password SQL memorizzate dall’app sono protette dalla cifratura di sistema quando disponibile. Puoi anche fornire una credenziale tramite variabile d’ambiente.

Il download di modelli, la preparazione degli ambienti di sviluppo e le anteprime con URL esterni possono contattare i servizi che scegli o quelli dichiarati nei tuoi progetti. GitHub gestisce la distribuzione dei sorgenti e dei file di release secondo la propria informativa.
